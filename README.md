<h1 align="center">smart-thumbnailer</h1>

Thumbnails generated by naive keyframe extraction tend to cluster around the same few seconds — you end up with six nearly identical frames from the same talking-head shot. `smart-thumbnailer` scores every candidate frame on sharpness, colorfulness, saliency, face count, and temporal stability, then picks one winner per time zone so the output actually covers the full video.

The face detector downloads itself on the first run (~2 MB). No GPU, no PyTorch, no cloud API.

## Features

- **Zone-based diversity** — splits the timeline into N equal zones, picks the top scorer from each; no frame clustering
- **Multi-metric scoring** — Tenengrad sharpness (center-weighted Sobel), Hasler & Süsstrunk colorfulness, spectral residual saliency (Hou & Zhang 2007), temporal stability, face detection, exposure
- **dHash deduplication** — drops near-identical frames before scoring (Hamming distance ≤ 12 of 64 bits)
- **Auto count** — scales thumbnail count with video duration (2 for short clips, up to 10 for feature-length)
- **Scene-aware sampling** — merges PySceneDetect cut points with uniform samples when the package is installed
- **Phone rotation correction** — reads `cv2.CAP_PROP_ORIENTATION_META`, rotates frames before scoring
- **Self-contained HTML report** — base64-embedded JPEGs with per-frame metric bars; open in any browser, no server

## Installation

```bash
pip install opencv-python numpy
```

Optional — enables scene-aware sampling at detected cut points:

```bash
pip install "scenedetect[opencv]"
```

Clone the repo (single file, no package install needed):

```bash
git clone https://github.com/fralapo/smart-thumbnailer.git
cd smart-thumbnailer
```

The face detection model (OpenCV DNN res10 SSD, ~2 MB) downloads automatically on the first run that uses it.

## Quick Start

```bash
python thumbnailer.py video.mp4
```

Output goes to `thumbnails/`:

```
thumbnails/
├── thumb_1_04m25s.jpg
├── thumb_2_07m15s.jpg
├── ...
├── report.json
└── preview.html
```

Open `preview.html` in a browser to compare all candidates side by side with metric bars.

## Usage

```
python thumbnailer.py VIDEO [options]
```

| Flag | Default | Description |
|---|---|---|
| `-o, --output` | `thumbnails/` | Output directory |
| `-k, --top-k` | auto | Thumbnail count (overrides auto-scale) |
| `-s, --sample-interval` | `5.0` | Seconds between uniform samples |
| `--skip-pct` | `0.05` | Skip this fraction at the start and end |
| `--jpeg-quality` | `95` | JPEG quality (1–100) |
| `--no-faces` | off | Skip face detection (faster) |
| `--no-scene-detect` | off | Skip PySceneDetect integration |

### Examples

```bash
# Auto count (13-min video → 6 thumbnails)
python thumbnailer.py talk.mp4

# Force 3 thumbnails into a custom dir
python thumbnailer.py talk.mp4 -o out/ -k 3

# Skip both optional detectors for speed
python thumbnailer.py talk.mp4 --no-faces --no-scene-detect

# Sample more densely (every 2 s instead of 5 s)
python thumbnailer.py talk.mp4 -s 2
```

## Auto Thumbnail Count

When `-k` is not set, count scales with duration:

| Duration | Thumbnails |
|---|---|
| < 3 min | 2 |
| 3–8 min | 4 |
| 8–20 min | 6 |
| 20–40 min | 8 |
| 40–70 min | 9 |
| 70–120 min | 10 |
| > 120 min | 10 (cap) |

## How It Works

```
video
  └─ uniform samples every Ns  +  PySceneDetect cuts (optional)
       └─ fast filter: drop dark (<22), overexposed (>233), blurry frames
            └─ dHash dedup: remove near-identical frames
                 └─ full scoring per frame:
                 │   Tenengrad sharpness (Sobel gradient energy, Gaussian center weight)
                 │   colorfulness  (Hasler & Süsstrunk 2003)
                 │   saliency      (spectral residual, Hou & Zhang CVPR 2007)
                 │   stability     (histogram correlation with temporal neighbors)
                 │   faces         (OpenCV DNN res10 SSD, confidence ≥ 0.50)
                 │   exposure
                 └─ zone selection: divide usable span into K zones, pick top per zone
                      └─ output: N × JPG  +  report.json  +  preview.html
```

Default scoring weights (constants in `thumbnailer.py`):

| Metric | Weight |
|---|---|
| Sharpness | 30% |
| Faces | 20% |
| Exposure | 12% |
| Contrast | 15% |
| Saliency | 10% |
| Colorfulness | 8% |
| Stability | 5% |

## Output Files

**`report.json`** includes video metadata, per-thumbnail scores, scoring weights, and whether face detection ran.

**`preview.html`** is fully self-contained — images are base64-embedded. When face detection is disabled, the Faces row shows N/A instead of misleading zeros.

## Requirements

- Python 3.9+
- `opencv-python >= 4.5`
- `numpy >= 1.20`
- `scenedetect[opencv]` — optional, for scene-aware sampling
